# Meeting Calendar

## Overview

Meeting Calendar is a scheduling application developed as part of my internship at the Bulgarian Academy of Sciences (BAS).

The application was created to organize meetings, participants, dates, and time slots through an interactive calendar interface. It supports individual and bulk scheduling, input validation, duplicate prevention, and persistent storage in the browser.

## Technologies

* HTML5
* CSS3
* JavaScript
* Local Storage

## Main Features

* Interactive calendar navigation
* Creation and management of meetings
* Individual and bulk participant scheduling
* Date and time validation
* Duplicate entry prevention
* Persistent browser storage using Local Storage
* Visual indication of invalid or unsuccessful entries

## Project Context

This project was developed during my internship at the Bulgarian Academy of Sciences as a practical scheduling solution and a demonstration of front-end development skills.
